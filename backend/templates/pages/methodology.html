{% trans 'Шкала загруженности' %}

{% trans 'Загруженность участка выражается целым баллом от нуля до десяти по шкале, принятой в практике городского мониторинга движения. Нулевое значение соответствует свободному движению с разрешённой скоростью, десятое — полной остановке потока. Для группировки в интерфейсе применяются четыре интервала.' %}

  • 0–4{% trans '— свободное движение и незначительные затруднения;' %}
  • 5–6{% trans '— затруднённое движение, скорость ниже разрешённой;' %}
  • 7–8{% trans '— пробки, движение с частыми остановками;' %}
  • 9–10{% trans '— движение практически остановлено.' %}

{% trans 'Средняя загруженность сети рассчитывается по последней оценке каждого участка, а не по всем записям за период: иначе участок с более длинным рядом получил бы непропорционально больший вес в итоге.' %}

{% trans 'Открытого потока сведений о загруженности по городу не существует: ведомственные системы его не публикуют. Величина рассчитывается имитационной моделью по классу дороги, числу полос и часу суток, помечается маркером «смоделировано» и в композитный индекс не входит.' %}

{% trans 'Композитный индекс логистической нагрузки' %}

{% trans 'Показатели округа измеряются в разных единицах, поэтому прямое их сложение лишено смысла. Применяется нормирование методом «минимум — максимум»: каждый показатель линейно отображается на отрезок от нуля до единицы, где ноль соответствует наименьшему значению в выборке, единица — наибольшему. Обратная составляющая при этом обращается: рост обеспеченности сетью означает снижение нагрузки.' %}

Поэтому он пригоден для ранжирования и выявления полярных случаев, но не является абсолютной мерой нагрузки.' %}

{% trans 'Типология округов' %}

{% trans 'Разбиение на однородные группы выполняется методом k-средних в пространстве четырёх стандартизованных показателей. Стандартизация обязательна: без неё расстояние между округами определялось бы почти исключительно объёмом грузопотока, измеряемым десятками тысяч тонн.' %}

{% trans 'Начальные центры выбираются по схеме k-means++, снижающей вероятность попадания в неудачный локальный минимум. Генератор случайных чисел зафиксирован, поэтому результат воспроизводим при повторных запусках — свойство, существенное для проверяемости расчётов.' %}

{% trans 'Прогнозирование грузопотока' %}

{% trans 'Применяется аддитивная модель: линейный тренд, оценённый методом наименьших квадратов, плюс сезонная составляющая, рассчитанная как среднее отклонение соответствующего месяца от линии тренда.' %}

{% trans 'Выбор в пользу простой модели обусловлен длиной ряда наблюдений. На коротких рядах методы класса SARIMA дают неустойчивые оценки параметров, и кажущаяся точность модели не соответствует её фактической предсказательной способности. Качество аппроксимации характеризуется коэффициентом детерминации и средней абсолютной процентной ошибкой; оба показателя выводятся на странице прогноза.' %}

{% trans 'Сценарное моделирование' %}

{% trans 'Заданное изменение переносится на исходные величины составляющих выбранного округа, после чего расчёт индекса повторяется целиком. Переносится сдвиг условий, а не отклик на него: коэффициентов отклика, подтверждённых наблюдениями по городу, не существует, а заданные экспертно определяли бы результат сильнее самих данных.' %}

{% trans 'Условие задаётся по одному округу. Нормирование относительное: изменение, заданное всем округам сразу, сдвинуло бы величины разом и оставило расстановку прежней.' %}
