# Программный интерфейс ИС «ГрузПоток»

Базовый адрес: `/api/v1/`

Машиночитаемая спецификация: `/api/v1/schema/` (OpenAPI 3).
Интерактивная документация: `/api/v1/docs/` и `/api/v1/redoc/`.

---

## 1. Общие сведения

### 1.1. Авторизация

Справочники и реестры доступны без авторизации — сведения являются
открытыми. Персональный токен требуется только для повышенных ограничений на
частоту обращений.

```http
Authorization: Token ВАШ_ТОКЕН
```

Токен выпускается в личном кабинете пользователями с ролью «Аналитик» и выше.

### 1.2. Ограничения на частоту

| Режим | Предел |
|---|---|
| Без авторизации | 60 запросов в минуту |
| По токену | 600 запросов в минуту |

При превышении возвращается код 429 и заголовок `Retry-After` с числом
секунд до следующей попытки.

### 1.3. Постраничный вывод

Все перечни возвращаются постранично.

| Параметр | Назначение | Умолчание |
|---|---|---|
| `page` | Номер страницы | 1 |
| `page_size` | Число записей | 25, не более 500 |

Структура ответа:

```json
{
  "count": 4231,
  "pages": 170,
  "page": 1,
  "page_size": 25,
  "next": "/api/v1/objects/?page=2",
  "previous": null,
  "results": []
}
```

### 1.4. Формат геометрии

Пространственные данные передаются в формате GeoJSON в системе координат
WGS-84 (EPSG:4326). Порядок координат — долгота, широта.

```json
{
  "type": "Point",
  "coordinates": [37.529410, 55.854143]
}
```

Ответ можно передать в картографическую библиотеку без преобразований.

### 1.5. Коды ответа

| Код | Значение |
|---|---|
| 200 | Запрос выполнен |
| 400 | Некорректные параметры запроса |
| 401 | Требуется авторизация |
| 403 | Недостаточно полномочий |
| 404 | Запись не найдена |
| 422 | Запрос корректен, но результат не может быть получен (например, недостаточно данных для прогноза) |
| 429 | Превышено ограничение на частоту |

## 2. Справочники

### `GET /api/v1/districts/`

Административные округа.

**Поля ответа:** `id`, `name`, `short_name`, `area_sq_km`, `population`,
`density`, `center`.

### `GET /api/v1/districts/summary/`

Агрегированные показатели округов: число объектов, суммарная мощность,
объём грузопотока, протяжённость дорожной сети, средняя загруженность.

### `GET /api/v1/types/`

Классификатор типов объектов с числом записей каждого типа.

### `GET /api/v1/cargo-categories/`

Классификатор категорий грузов с указанием класса опасности.

### `GET /api/v1/sources/`

Реестр источников данных.

## 3. Объекты инфраструктуры

### `GET /api/v1/objects/`

Реестр объектов.

| Параметр | Тип | Назначение |
|---|---|---|
| `district` | целое | Идентификатор округа |
| `type` | целое | Идентификатор типа объекта |
| `q` | строка | Поиск по наименованию и адресу |

**Пример:**

```bash
curl "https://freightflow.example.ru/api/v1/objects/?district=1&page_size=5"
```

### `GET /api/v1/objects/{id}/`

Карточка объекта.

### `GET /api/v1/objects/nearby/`

Объекты в заданном радиусе от точки.

| Параметр | Тип | Обязателен | Назначение |
|---|---|---|---|
| `lon` | вещественное | да | Долгота точки |
| `lat` | вещественное | да | Широта точки |
| `radius` | вещественное | нет | Радиус, км (по умолчанию 3, не более 25) |
| `limit` | целое | нет | Предел результатов (по умолчанию 20, не более 100) |

Результаты упорядочены по возрастанию расстояния; каждая запись дополнена
полем `distance_km`.

**Пример:**

```bash
curl "https://freightflow.example.ru/api/v1/objects/nearby/?lon=37.62&lat=55.75&radius=5"
```

## 4. Дорожная сеть

### `GET /api/v1/roads/`

Участки улично-дорожной сети.

| Параметр | Назначение |
|---|---|
| `district` | Идентификатор округа |
| `class` | Класс дороги: `highway`, `arterial`, `local`, `service` |

### `GET /api/v1/traffic/current/`

Последний замер обстановки по каждому участку.

| Параметр | Назначение |
|---|---|
| `district` | Ограничение выборки округом |

Поле `state` содержит кодовое обозначение, словесную оценку и модификатор
оформления состояния движения.

### `GET /api/v1/incidents/`

Журнал дорожных событий.

| Параметр | Назначение |
|---|---|
| `type` | Тип события |
| `state` | `open` — открытые, `closed` — устранённые |
| `severity` | Минимальный уровень серьёзности |
| `cargo` | `1` — только влияющие на грузовой транспорт |

Грузовые маршруты.

## 6. Аналитика

### `GET /api/v1/analytics/load-index/`

Композитный индекс логистической нагрузки округов.

```json
{
  "weights": {
    "capacity": 0.30,
    "flow": 0.30,
    "congestion": 0.25,
    "incidents": 0.15
  },
  "count": 12,
  "results": [
    {
      "rank": 1,
      "district_id": 5,
      "district": "Юго-Восточный",
      "short_name": "ЮВАО",
      "score": 87.4,
      "components": {
        "capacity": 92.1,
        "flow": 88.6,
        "congestion": 79.3,
        "incidents": 84.0
      }
    }
  ]
}
```

### `GET /api/v1/analytics/forecast/`

Прогноз объёма перевозок.

| Параметр | Назначение |
|---|---|
| `district` | Идентификатор округа (без него — по городу) |
| `horizon` | Горизонт прогноза, месяцев (3–12, по умолчанию 6) |

Возвращает историю наблюдений, прогнозные значения и оценку качества модели
(коэффициент детерминации и средняя абсолютная процентная ошибка).

При недостатке наблюдений возвращается код 422 с пояснением.

### `GET /api/v1/analytics/typology/`

Типология округов методом k-средних.

| Параметр | Назначение |
|---|---|
| `k` | Число групп (2–6, по умолчанию 4) |

## 8. Примеры использования

### Выгрузка всех объектов округа

```python
import requests

BASE = "https://freightflow.example.ru/api/v1"
objects, page = [], 1

while True:
    response = requests.get(
        f"{BASE}/objects/",
        params={"district": 1, "page": page, "page_size": 100},
        timeout=30,
    )
    response.raise_for_status()
    payload = response.json()
    objects.extend(payload["results"])
    if not payload["next"]:
        break
    page += 1

print(f"Получено объектов: {len(objects)}")
```

### Построение слоя карты

```javascript
fetch("/api/v1/objects/?district=1")
    .then(response => response.json())
    .then(payload => {
        const features = payload.results
            .filter(row => row.geometry)
            .map(row => ({
                type: "Feature",
                geometry: row.geometry,
                properties: { name: row.name, capacity: row.capacity_tons }
            }));
        L.geoJSON({ type: "FeatureCollection", features }).addTo(map);
    });
```

### Наблюдение за загруженностью сети

```bash
curl -s "https://freightflow.example.ru/api/v1/traffic/current/" \
  | python -c "
import json, sys
rows = json.load(sys.stdin)['results']
heavy = [r for r in rows if r['congestion_level'] >= 7]
print(f'Участков с затруднениями: {len(heavy)} из {len(rows)}')
for row in heavy:
    print(f\"  {row['road_name']}: {row['congestion_level']} — {row['state']['label']}\")
"
```
