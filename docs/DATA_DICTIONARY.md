# Словарь данных ИС «ГрузПоток»

Описание одиннадцати таблиц предметной области. Схема приведена в
`db/001_schema.sql`.

**Условные обозначения:** ПК — первичный ключ, ВК — внешний ключ,
NN — обязательное поле.

---

## Общие соглашения

| Аспект | Принятое решение |
|---|---|
| Система координат | WGS-84 (EPSG:4326), порядок — долгота, широта |
| Отметки времени | С указанием часового пояса, хранятся в UTC, отображаются в Europe/Moscow |
| Денежные и весовые величины | `NUMERIC` с явной точностью — не `FLOAT`, во избежание накопления погрешности |
| Удаление справочных записей | Запрещено при наличии ссылок (`ON DELETE RESTRICT`) |
| Удаление источника данных | Ссылка обнуляется (`ON DELETE SET NULL`) — сведения сохраняются |

---

## 1. `districts` — административные округа

Справочник территориального деления города.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| `id` | `SERIAL` | ПК | Идентификатор |
| `name` | `VARCHAR(100)` | NN, уникально | Наименование округа |
| `short_name` | `VARCHAR(20)` | NN, уникально | Общепринятая аббревиатура (ЦАО, САО) |
| `area_sq_km` | `NUMERIC(10,2)` | > 0 | Площадь, км² |
| `population` | `INTEGER` | ≥ 0 | Численность населения, человек |
| `geom` | `GEOMETRY(MultiPolygon,4326)` | | Границы округа |
| `center` | `GEOMETRY(Point,4326)` | | Условный центр для размещения подписи на карте |

**Производные характеристики:** плотность населения (отношение численности к
площади), центр для карты (координаты `center` либо центроид границ).

---

## 2. `infrastructure_types` — типы объектов

Классификатор объектов логистической инфраструктуры.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| `id` | `SERIAL` | ПК | Идентификатор |
| `code` | `VARCHAR(50)` | NN, уникально | Машинный код (`warehouse`, `terminal`) |
| `name` | `VARCHAR(100)` | NN | Наименование для интерфейса |
| `description` | `TEXT` | | Пояснение к типу |

**Значения:** склад, грузовой терминал, грузовой двор, грузовая парковка,
контрольный пункт, распределительный центр.

---

## 3. `cargo_categories` — категории грузов

Классификатор перевозимых грузов с указанием класса опасности.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| `id` | `SERIAL` | ПК | Идентификатор |
| `code` | `VARCHAR(50)` | NN, уникально | Машинный код |
| `name` | `VARCHAR(100)` | NN | Наименование категории |
| `hazard_class` | `SMALLINT` | 0–9 | Класс опасности по ДОПОГ; 0 — неопасный груз |

**Примечание.** Ненулевой класс опасности означает необходимость согласования
маршрута и времени движения, что учитывается при анализе маршрутной сети.

---

## 4. `data_sources` — источники данных

Реестр внешних источников с указанием регламента обновления.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| `id` | `SERIAL` | ПК | Идентификатор |
| `code` | `VARCHAR(50)` | NN, уникально | Машинный код источника |
| `name` | `VARCHAR(200)` | NN | Наименование организации или системы |
| `source_type` | `VARCHAR(30)` | NN | Тип: `api`, `file`, `manual`, `portal` |
| `url` | `VARCHAR(500)` | | Адрес источника |
| `update_frequency` | `VARCHAR(30)` | | Периодичность: `realtime`, `daily`, `weekly`, `monthly`, `irregular` |
| `is_active` | `BOOLEAN` | NN | Признак действующего источника |

---

## 5. `infrastructure_objects` — объекты инфраструктуры

Основной реестр системы.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| `id` | `SERIAL` | ПК | Идентификатор |
| `type_id` | `INTEGER` | ВК → `infrastructure_types`, NN | Тип объекта |
| `district_id` | `INTEGER` | ВК → `districts`, NN | Округ размещения |
| `name` | `VARCHAR(300)` | NN | Наименование объекта |
| `address` | `VARCHAR(500)` | | Почтовый адрес |
| `capacity_tons` | `NUMERIC(12,2)` | ≥ 0 | Проектная мощность хранения, т |
| `area_sq_m` | `NUMERIC(12,2)` | ≥ 0 | Площадь, м² |
| `operating_hours` | `VARCHAR(100)` | | Режим работы в свободной форме |
| `geom` | `GEOMETRY(Point,4326)` | | Координаты размещения |
| `source_id` | `INTEGER` | ВК → `data_sources` | Источник сведений |
| `created_at` | `TIMESTAMPTZ` | NN | Время создания записи |
| `updated_at` | `TIMESTAMPTZ` | NN | Время последнего изменения |

**Индексы:** по округу, по типу, пространственный GiST по `geom`,
триграммный по `name` для поиска подстроки.

**Производные характеристики:** удельная мощность (отношение мощности к
площади — косвенно указывает на технологию хранения), признак круглосуточной
работы (определяется по тексту поля режима работы).

## 8. `traffic_conditions` — замеры дорожной обстановки

Наиболее объёмная таблица наблюдений.

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| `id` | `SERIAL` | ПК | Идентификатор |
| `road_id` | `INTEGER` | ВК → `road_segments`, NN | Участок сети |
| `recorded_at` | `TIMESTAMPTZ` | NN | Время замера |
| `congestion_level` | `SMALLINT` | 0–10, NN | Балл загруженности |
| `avg_speed_kmh` | `NUMERIC(6,2)` | ≥ 0 | Средняя скорость потока, км/ч |
| `travel_time_min` | `NUMERIC(8,2)` | ≥ 0 | Время проезда участка, мин |
| `vehicle_density` | `INTEGER` | ≥ 0 | Плотность потока, ТС/км |
| `incident_flag` | `BOOLEAN` | NN | Признак наличия происшествия |
| `source_id` | `INTEGER` | ВК → `data_sources` | Источник сведений |

**Индексы:** составной по паре «участок — время замера» (убывание) — под
типовой запрос последнего замера.

**Шкала загруженности:**

| Балл | Состояние движения |
|---|---|
| 0–2 | Свободное |
| 3–4 | Незначительные затруднения |
| 5–6 | Затруднённое |
| 7–8 | Пробки |
| 9–10 | Движение остановлено |

## 9. `traffic_incidents` — дорожные события

| Поле | Тип | Ограничения | Описание |
|---|---|---|---|
| `id` | `SERIAL` | ПК | Идентификатор |
| `reported_at` | `TIMESTAMPTZ` | NN | Время регистрации |
| `resolved_at` | `TIMESTAMPTZ` | | Время устранения; `NULL` — событие открыто |
| `incident_type` | `VARCHAR(30)` | NN | Тип: `accident`, `roadworks`, `restriction`, `weather`, `other` |
| `severity` | `SMALLINT` | 1–5, NN | Уровень серьёзности |
| `road_id` | `INTEGER` | ВК → `road_segments` | Участок сети |
| `description` | `TEXT` | | Описание события |
| `geom` | `GEOMETRY(Point,4326)` | | Место события |
| `affects_cargo` | `BOOLEAN` | NN | Влияние на грузовой транспорт |
| `source_id` | `INTEGER` | ВК → `data_sources` | Источник сведений |

**Индексы:** по времени регистрации (убывание), частичный по открытым
событиям (`WHERE resolved_at IS NULL`).

**Шкала серьёзности:**

| Уровень | Признак |
|---|---|
| 1 | Незначительный: помеха движению |
| 2 | Умеренный: сужение проезжей части |
| 3 | Значительный: перекрытие полосы |
| 4 | Серьёзный: перекрытие направления |
| 5 | Критический: полное перекрытие |

## Представления

Помимо таблиц схема содержит два представления (`db/003_views.sql`).

### `v_district_summary`

Агрегированные показатели округов: число объектов, суммарная мощность
хранения, протяжённость дорожной сети, объём грузопотока.

### `v_current_traffic`

Последний замер обстановки для каждого участка сети с присоединёнными
сведениями об участке и округе.
