# Руководство пользователя ИС «ГрузПоток»

Документ предназначен для пользователей системы всех ролей. Порядок
администрирования изложен в отдельном документе
[ADMIN_GUIDE.md](ADMIN_GUIDE.md).

---

## 1. Начало работы

### 1.1. Доступ без регистрации

Реестры, карта, аналитика и материалы доступны без авторизации. Регистрация
требуется для ведения избранного, сохранения условий отбора, подписок и
выгрузки отчётов.

### 1.2. Регистрация

1. Нажмите «Войти» в правом верхнем углу, затем «Зарегистрируйтесь».
2. Заполните фамилию, имя, имя пользователя, адрес электронной почты и пароль.
3. Поле «Организация» заполняется при намерении запросить расширенные права.

Новой учётной записи назначается роль «Наблюдатель». Расширение полномочий
выполняет администратор по запросу через форму обратной связи.

### 1.3. Язык интерфейса

Переключатель языка расположен в шапке страницы: **RU** и **EN**. Выбор
сохраняется и действует до следующего переключения.

Переводится интерфейс: навигация, заголовки, подписи полей, кнопки, таблицы,
пояснительные тексты. Наименования объектов, округов и источников данных
остаются на языке исходных сведений — это содержание базы, а не интерфейс.

### 1.4. Оформление интерфейса

Значок в шапке переключает оформление по кругу: тёмное → светлое → как в
операционной системе. Каждому режиму соответствует свой знак — луна, солнце
и монитор, — поэтому выбранный режим виден без наведения. Выбор сохраняется
в браузере и применяется до отрисовки страницы, без промежуточного
перекрашивания.

Тёмное оформление принято основным: система предназначена для длительной
работы с таблицами и картой, в том числе в помещениях с приглушённым
освещением.

## 2. Главная страница

Страница даёт оперативную картину состояния логистической системы города.

**Лента состояния сети** — горизонтальная полоса под заголовком. Каждый
сегмент соответствует участку улично-дорожной сети и окрашен по текущему
баллу загруженности. Сегменты упорядочены по возрастанию загруженности:
слева спокойные направления, справа проблемные. Наведение показывает
название участка и показатели, нажатие открывает карточку.

**Плитки показателей** — пять ключевых величин. Цветная полоса слева
указывает состояние по семафорной шкале. Каждая плитка ведёт в
соответствующий раздел.

**График динамики** — помесячный объём перевозок. Наведение на точку
показывает значение за месяц.

**Таблицы и перечни** — округа с наибольшим грузопотоком, наиболее
загруженные участки, последние дорожные события, аналитические материалы.

## 3. Работа с реестрами

### 3.1. Условия отбора

Панель над таблицей содержит поля отбора. Выбор значения в выпадающем списке
применяется немедленно, без нажатия кнопки. Для текстового поиска нажмите
«Показать».

Условия комбинируются: одновременно можно задать округ, тип объекта,
поисковый запрос и дополнительные признаки.

Кнопка «Очистить» снимает все условия.

### 3.2. Сортировка

Нажатие на заголовок колонки упорядочивает записи по её значению. Повторное
нажатие меняет направление. Активная колонка отмечена указателем направления.

Наложенные условия отбора при сортировке сохраняются.

### 3.3. Постраничный вывод

Под таблицей отображается диапазон показанных записей и общее их число.
Переход между страницами не сбрасывает условия отбора и порядок сортировки.

### 3.4. Переход к карточке

Нажатие в любом месте строки открывает карточку записи. Ссылки внутри строки
при этом работают обычным образом.

## 4. Карта

### 4.1. Слои

Панель слева содержит пять независимо подключаемых слоёв:

| Слой | Содержание |
|---|---|
| Объекты инфраструктуры | Точки размещения складов и терминалов |
| Дорожная сеть | Участки, окрашенные по загруженности |
| Дорожные события | Точки происшествий; размер отражает серьёзность |
| Грузовые маршруты | Транспортные коридоры штриховой линией |
| Округа с показателями | Подписи с числом объектов |

Слои загружаются при включении. Под каждым выводится число загруженных
объектов.

### 4.2. Условия отбора на карте

Списки «Округ» и «Тип объекта» ограничивают состав отображаемых слоёв.
Изменение условия перезагружает включённые слои.

### 4.3. Поиск объектов вблизи точки

1. Задайте радиус поиска в километрах.
2. Нажмите «Что рядом с точкой».
3. Укажите точку на карте.

На карте отображаются метка и окружность радиуса; в панели — перечень
найденных объектов с расстояниями, упорядоченный по возрастанию.

Инструмент применяется при оценке обеспеченности территории складскими
мощностями и при подборе площадки под новый объект.

### 4.4. Сведения об объекте

Нажатие на объект карты открывает всплывающую подсказку с основными
характеристиками и ссылкой на полную карточку.

## 5. Дорожная обстановка

### 5.1. Сводка

Раздел «Дорожная сеть» → «Обстановка» показывает средний балл загруженности
по городу, число участков под наблюдением, час максимальной нагрузки и
среднюю скорость за неделю.

### 5.2. Суточный профиль

Столбчатая диаграмма отображает средний балл загруженности по часам суток за
две недели наблюдений. Профиль имеет два выраженных пика — утренний и
вечерний; между ними располагается интервал относительно свободного движения.

Сведения применимы при планировании доставки: перенос рейса в межпиковый
интервал сокращает время в пути и повышает предсказуемость расписания.

### 5.3. Журнал событий

Раздел «Инциденты» содержит перечень дорожных событий с указанием типа,
серьёзности, участка и длительности. Отбор позволяет выделить открытые
события, события выше заданного уровня серьёзности и влияющие на грузовой
транспорт.

## 6. Аналитические разделы

### 6.1. Индекс логистической нагрузки

Композитная оценка сводит четыре показателя округа к единой стобалльной
шкале. Округа упорядочены по убыванию индекса.

**Как читать значение.** Индекс отражает положение округа относительно
других округов, а не абсолютный уровень нагрузки. Высокое значение не
означает проблему само по себе: оно может отражать концентрацию складских
мощностей, то есть развитость инфраструктуры.

Смысл конкретного значения раскрывают составляющие. Сочетание высокой
загруженности при низких мощностях указывает на транзитную перегрузку;
обратное сочетание — на логистический узел с достаточной пропускной
способностью.

### 6.2. Типология округов

Разбиение на однородные группы методом k-средних. Число групп задаётся
пользователем в пределах от двух до шести.

Результат воспроизводим: при одних и тех же данных повторное обращение даёт
тот же состав групп.

### 6.3. Прогноз грузопотока

Оценка объёма перевозок на ближайшие месяцы. График содержит фактическую
часть сплошной линией и прогнозную — штриховой.

**Оценка достоверности.** Средняя абсолютная процентная ошибка ниже 10 %
считается высоким качеством, от 10 до 20 % — приемлемым, свыше 20 % —
низким. В последнем случае прогноз следует трактовать как ориентировочный.

Прогноз описывает продолжение сложившихся тенденций и не учитывает изменения
условий — ввод новых мощностей, изменение режима допуска транспорта, крупные
ремонтные работы. Для оценки таких изменений предназначен сценарный расчёт.

### 6.4. Сравнение округов

Отметьте от двух округов и нажмите «Сравнить». Таблица сопоставления
показывает индекс, его составляющие и дополнительные показатели.

### 6.5. Сценарный расчёт

Задайте изменение объёма перевозок, складских мощностей и пропускной
способности сети в процентах. Система пересчитывает индекс и показывает
направление изменения по каждому округу.

Результат следует трактовать как оценку направления и порядка изменений, а
не как точный прогноз: коэффициенты отклика заданы экспертно.

## 7. Выгрузка отчётов

Доступна с роли «Аналитик».

### 7.1. Порядок

1. Откройте реестр и наложите нужные условия отбора.
2. В заголовке страницы выберите формат: XLSX, DOCX, PDF, CSV или GeoJSON.
3. Файл формируется и становится доступен в разделе «Выгрузки» личного
   кабинета.

Выгружается ровно та выборка, которая отображается на экране.

### 7.2. Выбор формата

| Формат | Когда применять |
|---|---|
| **XLSX** | Дальнейшая обработка в табличном процессоре; содержит лист со сведениями о выгрузке |
| **DOCX** | Включение в отчётные материалы; альбомная разметка, сводка показателей |
| **PDF** | Печать и рассылка; выводится не более 400 записей |
| **CSV** | Импорт в другие системы; открывается без мастера импорта |
| **GeoJSON** | Загрузка в картографическое приложение; записи без координат не включаются |

### 7.3. Срок хранения

Сформированные файлы хранятся четырнадцать суток, после чего удаляются
автоматически. Отчёт всегда можно сформировать заново — данные при этом
будут актуальными на момент повторной выгрузки.

## 8. Личный кабинет

### 8.1. Избранное

Кнопка «В избранное» на карточке объекта, округа или участка добавляет
закладку. Перечень доступен в разделе «Избранное» с отбором по типу.

### 8.2. Сохранённые виды

Настроенные условия отбора сохраняются под именем и открываются одним
нажатием. Сохраняются именно условия, а не данные: при открытии выборка
выполняется заново и показывает актуальные значения.

**Публикация по ссылке.** Кнопка «Открыть по ссылке» формирует адрес,
доступный без авторизации. Применяется для передачи коллегам конкретной
выборки. Доступ закрывается кнопкой «Закрыть доступ».

### 8.3. Подписки на события

Оформите подписку на дорожные события выбранного округа с указанием
минимального уровня серьёзности. При наступлении события формируется
уведомление.

### 8.4. Доступ к программному интерфейсу

Раздел «Доступ к API» позволяет выпустить персональный токен. Токен
требуется только для повышенных ограничений на частоту обращений: сами
данные доступны и без него.

Токен следует хранить как пароль — он даёт доступ от имени владельца.
Повторный выпуск отзывает предыдущее значение.

### 8.5. Журнал действий

Раздел «Журнал» содержит записи о входах, изменениях данных и выгрузках с
указанием времени и адреса подключения. Обращения к страницам просмотра не
фиксируются.

## 9. Обратная связь

Форма расположена в разделе «Справка» → «Обратная связь». Укажите тему
обращения:

| Тема | Когда выбирать |
|---|---|
| Замечание к данным | Обнаружено несоответствие сведений действительности |
| Ошибка в работе | Раздел работает не так, как описано |
| Предложение | Идея по развитию системы |
| Запрос доступа | Требуется расширение полномочий |
| Иное | Прочие вопросы |

Ответ направляется на указанный адрес электронной почты в течение трёх
рабочих дней.

## 10. Часто задаваемые вопросы

**Почему объект не отображается на карте?**
У записи отсутствуют координаты. Такие объекты присутствуют в реестре, но не
могут быть размещены на карте. Показатели полноты данных приведены в разделе
«Источники данных».

**Почему значения показателей на разных страницах различаются?**
Сводки кешируются на несколько минут. После загрузки новых данных
расхождение устраняется автоматически либо по команде администратора.

**Почему прогноз недоступен для выбранного округа?**
Для построения модели требуется не менее четырёх помесячных наблюдений.
Выберите другой округ либо снимите условие отбора.

**Можно ли получить данные программно?**
Да. Программный интерфейс описан в разделе «Данные» → «REST API».
Справочники и реестры доступны без авторизации.

**Как запросить расширение прав?**
Через форму обратной связи с темой «Запрос доступа», указав организацию и
характер выполняемых задач.
