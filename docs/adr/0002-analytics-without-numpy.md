# ADR-0002. Аналитическое ядро на стандартной библиотеке

- **Статус:** принято
- **Дата:** 2026-06-22
- **Контекст:** выбор инструментов для расчётных функций

## Контекст

Аналитический раздел выполняет четыре вида расчётов: нормирование разнородных
показателей, кластеризацию округов методом k-средних, оценку параметров
линейной модели методом наименьших квадратов и прогнозирование временного
ряда.

Типовое решение — библиотеки `numpy`, `pandas` и `scikit-learn`.

## Рассмотренные варианты

### Вариант 1. numpy, pandas и scikit-learn

*Достоинства:* готовые проверенные реализации, высокая производительность на
больших массивах, широкий выбор алгоритмов.

*Недостатки:*

- суммарный объём зависимостей превышает 150 МБ;
- расчётные объёмы системы — двенадцать округов и до нескольких десятков
  тысяч записей наблюдений — не требуют векторизации;
- в рамках квалификационной работы алгоритм, скрытый за вызовом библиотечной
  функции, труднее представить и защитить, чем реализованный явно;
- воспроизводимость результата кластеризации требует отдельного управления
  состоянием генератора случайных чисел библиотеки.

### Вариант 2. Стандартная библиотека Python (принят)

*Достоинства:*

- отсутствие тяжёлых зависимостей;
- алгоритмы видны в исходном тексте и допускают построчную проверку;
- полный контроль над инициализацией генератора случайных чисел, а значит —
  воспроизводимость результатов;
- каждая функция чиста и покрывается модульными тестами напрямую.

*Недостатки:*

- реализация занимает около 220 строк, которые требуют собственных проверок;
- при росте объёма данных на несколько порядков потребуется переход на
  векторизованные вычисления.

## Решение

Принят вариант 2. Реализованы:

- `min_max_normalize` — приведение ряда к отрезку [0, 1] с корректной
  обработкой вырожденного случая (все значения равны);
- `z_scores` — стандартизация к нулевому среднему и единичному отклонению;
- `k_means` — кластеризация с инициализацией по схеме k-means++ и
  фиксированным зерном генератора;
- `linear_regression` — оценка параметров и коэффициента детерминации.

## Последствия

**Положительные.** Установка зависимостей занимает секунды. Все расчётные
функции покрыты модульными тестами, включая вырожденные случаи: пустой ряд,
ряд из одинаковых значений, единственное наблюдение. Результат кластеризации
воспроизводится в точности при повторных запусках, что проверяется
автотестом.

**Отрицательные.** При увеличении числа объектов кластеризации на два-три
порядка потребуется замена реализации. Граница применимости оценивается
примерно в десять тысяч объектов при четырёх признаках.

**Оценка производительности.** Кластеризация двенадцати округов по четырём
признакам выполняется менее чем за одну миллисекунду; результат кешируется,
поэтому влияние на время отклика страницы отсутствует.
