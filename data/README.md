# Каталог данных

| Файл | Назначение |
|------|-----------|
| `freightflow.sqlite3` | Демонстрационная база: схема и наполнение для немедленного запуска системы после клонирования репозитория |

Файл базы включён в репозиторий сознательно: он позволяет развернуть работающую
систему одной командой, без установки PostgreSQL и загрузки наборов данных.
Промышленный контур использует PostgreSQL с расширением PostGIS — сценарии
создания схемы и наполнения находятся в каталоге `db/`.

Пересоздать демонстрационную базу:

```
python backend/manage.py migrate
python backend/manage.py load_seed db/002_seed_data_scale1.sql
python backend/manage.py init_demo
```
