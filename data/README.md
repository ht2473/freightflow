# Каталог данных

| Файл | Назначение |
|------|-----------|
| `freightflow.sqlite3` | База: схема и наполнение для немедленного запуска системы после клонирования репозитория |
| `osm/` | Сохранённые ответы Overpass API |
| `reference/` | Справочные наборы, ведущиеся вручную, и книги статистических публикаций |

Файл базы включён в репозиторий сознательно: он позволяет развернуть работающую
систему одной командой, без установки PostgreSQL и без обращения к внешним
службам. Промышленный контур использует PostgreSQL с расширением PostGIS —
сценарии создания схемы находятся в каталоге `db/`.

## Кеш выгрузок

Ответы Overpass API сохраняются в `osm/` под именем, образованным отпечатком
текста запроса. Кеш решает три задачи: повторная загрузка не создаёт нагрузки
на общедоступную службу, набор проверок исполняется без обращения к сети,
а результат загрузки воспроизводим — по сохранённому ответу видно, какие
именно данные легли в базу и когда они были получены.

Правка текста запроса меняет отпечаток и потому автоматически приводит
к новой загрузке.

## Пересоздание базы

```bash
python backend/manage.py migrate
python backend/manage.py etl --all --prune
python backend/manage.py simulate_traffic --replace
python backend/manage.py setup_roles
python backend/manage.py init_demo
```

Первая загрузка обращается к внешним службам; последующие обслуживаются
из кеша, если не указан ключ `--refresh`. Ключ `--offline` запрещает обращение
в сеть и отказывает при отсутствии сохранённого ответа.
