# Справочные наборы

Наборы, которые не публикуются машиночитаемо и потому ведутся в проекте
как файлы. Каждый файл содержит указание на источник и дату сверки —
по ним видно, откуда взяты сведения и когда они проверялись.

Файлы загружаются командой `manage.py load_reference` и участвуют в тех же
проверках качества, что и данные, полученные из внешних служб.

| Файл | Содержание | Источник |
|---|---|---|
| `freight_frame.json` | Магистрали грузового каркаса Москвы | Департамент транспорта, transport.mos.ru |
| `freight_statistics.json` | Ряды перевозок грузов автотранспортом | Росстат, ЕМИСС |

## Как пополнять

Значения вносятся только из первоисточника, с указанием издания и даты.
Пустое поле честнее заполненного по догадке: незаполненное сведение видно
в отчёте о качестве данных и может быть уточнено, тогда как выдуманное
неотличимо от настоящего.
