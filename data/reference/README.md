# Справочные наборы

Наборы, которые не публикуются машиночитаемо и потому ведутся в проекте
как файлы. Каждый файл содержит указание на источник и дату сверки —
по ним видно, откуда взяты сведения и когда они проверялись.

Файлы загружаются командой `manage.py etl reference.frame rosstat.freight`
и проходят тот же конвейер, что и данные внешних служб: те же проверки
качества, тот же журнал, тот же карантин.

| Файл | Содержание | Источник |
|---|---|---|
| `freight_frame.json` | Магистрали грузового каркаса Москвы | Департамент транспорта, transport.mos.ru |
| `freight_statistics.json` | Состав рядов перевозок и грузооборота | Росстат, раздел «Транспорт» |
| `rosstat/*.xlsx` | Сами книги публикации Росстата | Росстат, раздел «Транспорт» |

Книги Росстата лежат в каталоге `rosstat` в том виде, в каком они опубликованы,
и читаются загрузчиком напрямую. Промежуточного файла с переписанными числами
нет намеренно: значение в базе прослеживается до ячейки первоисточника,
а `freight_statistics.json` описывает только состав рядов и разметку листов.

## Как пополнять

Значения вносятся только из первоисточника, с указанием издания и даты.
Пустое поле честнее заполненного по догадке: незаполненное сведение видно
в отчёте о качестве данных и может быть уточнено, тогда как выдуманное
неотличимо от настоящего.
